# Civitas

Interface para uma plataforma de um sistema integrado de serviços digitais, participação cidadã e gestão da infraestrutura urbana.

## Sobre o Projeto

O Civitas foi desenvolvido como trabalho prático para a disciplina de frontend, inspirado no desafio tecnológico proposto pela Usina Pernambucana de Inovação. A ideia principal baseia-se em uma plataforma no modelo SaaS, oferecendo um aplicativo multisserviços para o cidadao e um painel analítico para a gestão pública.

## Problema Resolvido

Criar uma solução digital para o registro georreferenciado de chamados de zeladoria urbana, com suporte a mídias e integração com sistemas administrativos, eliminando a necessidade de triagem manual.

## Como Usar a Aplicacao

* **Inicio**: Exibe a saudação ao usuário, barra de busca, atalho para registro de chamados, status do chamado em andamento e acesso rápido a serviços como Ouvidoria, Telefones úteis, Defesa Civil e Unidades de saúde.
* **Novo Chamado**: Formulário para registrar solicitações preenchendo o tipo de serviço, endereço e descrição do problema.
* **Chamados**: Tela de listagem que apresenta o histórico de solicitações registradas com seus respectivos status.
* **Perfil**: Exibe as informações cadastrais do usuário.
* **Notificacoes**: Área dedicada a avisos e atualizações sobre o andamento dos chamados.
