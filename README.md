## Civitas

Interface para uma plataforma de um sistema integrado de serviços digitais, participação cidadã e gestão da infraestrutura urbana.

Problema a ser resolvido: Criar uma plataforma de um sistema integrado de serviços digitais, participação cidadã e gestão da infraestrutura urbana. No estilo SaaS, composta por um Aplicativo Móvel multisserviços (Android e/ou iOS) para o cidadão e um Painel Web Administrativo analítico para a gestão pública.
